This draft describes data handling found in the NOW — Daily Planner app and server code reviewed for this version. It does not describe device-platform or provider practices that have not been verified.

Information stored on your device

NOW stores information you enter in local app storage on your device. This can include activities (names, dates, start and end times, categories, notes, and completion status); study tasks; workout and sports sessions; meals and nutrition targets or plans; personal goals; profile details; and your language selection.

Profile details may include your display name, schedule and availability, study interests and goals, training preferences and limitations, food preferences, disliked ingredients, allergies, dietary restrictions, meal schedule, cooking preferences, and nutrition goals. Some of these details may reveal sensitive health-related information.

The reviewed app has no user sign-in and does not save activities or profile records to a NOW application database. Local storage is implemented with AsyncStorage; the code reviewed does not establish that this storage is encrypted or how operating-system backups may handle it.

AI planning and coaching

When you request AI features, the app sends a request to the NOW server, which sends feature-specific content to OpenAI. The OpenAI API key is used by the server, not embedded in the mobile app. Avoid entering information in a prompt that you do not want sent for AI processing.

  • Plan my day: OpenAI receives your free-text request, local date and time, time zone, and up to 300 existing activity blocks containing names, dates, and start/end times. When you regenerate a plan, the current draft and names of activities you removed may also be sent. The app sends an optional profile subset to the NOW server, but the current day-planning route does not include that profile in its OpenAI request.
  • Workout Coach: OpenAI receives selected training profile fields (goal, experience, preferred days, availability, equipment, exercise preferences, and limitations), plus activity names, dates, and times for the next seven days, local date, and time zone.
  • Nutrition Coach: OpenAI receives non-empty food preferences, disliked ingredients, allergies, dietary restrictions, meal schedule, cooking preferences, and nutrition goals, plus local date and time zone. This request does not include the activity schedule.

AI results are returned to the app. In the reviewed flows, you can review the result before confirming it for local saving. OpenAI’s retention, use, and processing terms depend on the applicable provider account and settings; those details have not been verified for this draft.

Subscriptions and RevenueCat

NOW uses the RevenueCat SDK to load offerings and customer information and to support purchases and restores. The app uses a RevenueCat App User ID for entitlement checks; the NOW server uses that ID to ask RevenueCat whether the Premium entitlement is active. The reviewed app code does not send your activities or profile to RevenueCat. RevenueCat and the relevant Apple App Store or Google Play store process subscription and transaction information under their own terms. The exact provider-side data handling has not been independently verified here.

Service operation and rate limits

To apply AI request limits, the NOW server stores rate-limit records in its database. These include hashes derived from the RevenueCat App User ID and request IP address, along with a request count and time-window/expiry fields. When a later rate-limit request runs the cleanup query, it deletes rows whose expiry is more than seven days in the past; the timing depends on later requests and is not a fixed deletion guarantee. These hashed identifiers may still be linkable and should not be treated as guaranteed anonymous data.

The reviewed application logger records request ID, method, path, and response status rather than request bodies or IP addresses. Hosting-provider infrastructure logging was not reviewed.

Analytics, accounts, and advertising

No app-level analytics or advertising-tracking implementation was found in the reviewed app and server source. NOW currently has no user account sign-in. This statement is limited to the code reviewed; it does not describe data collection by device operating systems, app stores, or third-party providers.

Deletion and retention

You can delete some individual records in the app and clear profile information from the Profile screen. NOW does not currently provide a single control to delete all local data, an account-deletion feature, or a delete action for saved nutrition plans. Rate-limit records follow the cleanup behavior described above. Provider retention and device-backup retention have not been verified, so this draft makes no guarantee about them.

Este borrador describe el tratamiento de datos que aparece en el código de la aplicación y el servidor de NOW — Daily Planner revisado para esta versión. No describe prácticas de plataformas o proveedores que no se hayan verificado.

Información guardada en tu dispositivo

NOW guarda la información que introduces en el almacenamiento local de la aplicación en tu dispositivo. Puede incluir actividades (nombres, fechas, horas de inicio y fin, categorías, notas y estado de finalización); tareas de estudio; sesiones de entrenamiento y deportes; comidas y objetivos o planes nutricionales; metas personales; datos del perfil; y el idioma seleccionado.

Los datos del perfil pueden incluir tu nombre visible, horario y disponibilidad, intereses y metas de estudio, preferencias y limitaciones de entrenamiento, preferencias de comida, ingredientes que no te gustan, alergias, restricciones alimentarias, horarios de comidas, preferencias de cocina y objetivos nutricionales. Algunos de estos datos pueden revelar información sensible relacionada con la salud.

La aplicación revisada no tiene inicio de sesión y no guarda actividades ni perfiles en una base de datos de NOW. El almacenamiento local usa AsyncStorage; el código revisado no demuestra que esté cifrado ni indica cómo pueden tratarlo las copias de seguridad del sistema operativo.

Planificación y asesoramiento con IA

Cuando solicitas funciones de IA, la aplicación envía una solicitud al servidor de NOW, que envía a OpenAI el contenido correspondiente a cada función. La clave de OpenAI se usa en el servidor y no está incluida en la aplicación móvil. Evita introducir en un prompt información que no quieras enviar para su procesamiento mediante IA.

  • Planifica mi día: OpenAI recibe tu solicitud en texto libre, fecha y hora locales, zona horaria y hasta 300 actividades existentes con nombre, fecha y horas de inicio y fin. Al regenerar un plan, también pueden enviarse el borrador actual y los nombres de las actividades que quitaste. La aplicación envía al servidor de NOW un subconjunto opcional del perfil, pero la ruta actual de planificación diaria no lo incluye en la solicitud a OpenAI.
  • Entrenador de entrenamiento: OpenAI recibe algunos campos del perfil de entrenamiento (objetivo, experiencia, días preferidos, disponibilidad, equipo, preferencias de ejercicios y limitaciones), además de nombres, fechas y horarios de actividades de los próximos siete días, fecha local y zona horaria.
  • Entrenador de nutrición: OpenAI recibe los campos no vacíos de preferencias de comida, ingredientes que no te gustan, alergias, restricciones alimentarias, horario de comidas, preferencias de cocina y objetivos nutricionales, además de fecha local y zona horaria. Esta solicitud no incluye el horario de actividades.

Los resultados de IA se devuelven a la aplicación. En los flujos revisados puedes revisar el resultado antes de confirmarlo para guardarlo localmente. La conservación, el uso y el tratamiento de datos por OpenAI dependen de la cuenta y la configuración aplicables del proveedor; esos detalles no se han verificado para este borrador.

Suscripciones y RevenueCat

NOW usa el SDK de RevenueCat para cargar ofertas e información del cliente y permitir compras y restauraciones. La aplicación usa un identificador de usuario de RevenueCat para comprobar el acceso; el servidor de NOW utiliza ese identificador para consultar a RevenueCat si la suscripción Premium está activa. El código revisado no envía a RevenueCat tus actividades ni tu perfil. RevenueCat y la tienda correspondiente de Apple o Google procesan información de suscripciones y transacciones según sus propias condiciones. El tratamiento exacto de datos por esos proveedores no se ha verificado de forma independiente en este borrador.

Funcionamiento del servicio y límites de uso

Para aplicar límites a las solicitudes de IA, el servidor de NOW guarda registros en su base de datos. Incluyen hashes derivados del identificador de usuario de RevenueCat y de la IP de la solicitud, además de un contador y campos de ventana de tiempo y caducidad. Cuando una solicitud posterior ejecuta la consulta de limpieza, se eliminan las filas cuya caducidad lleva más de siete días vencida; el momento depende de solicitudes posteriores y no es una garantía de eliminación en un plazo fijo. Estos identificadores con hash aún podrían permitir relacionar registros y no deben considerarse anónimos de forma garantizada.

El registrador de la aplicación revisada guarda el identificador de solicitud, método, ruta y estado de respuesta, no el cuerpo de la solicitud ni la IP. No se revisaron los registros de infraestructura del proveedor de alojamiento.

Analítica, cuentas y publicidad

No se encontró una implementación de analítica de la aplicación ni de seguimiento publicitario en el código revisado de la aplicación y el servidor. NOW actualmente no tiene inicio de sesión de usuario. Esta afirmación se limita al código revisado; no describe la recopilación de datos de los sistemas operativos, las tiendas de aplicaciones o proveedores externos.

Eliminación y conservación

Puedes borrar algunos registros individuales en la aplicación y limpiar la información del perfil desde la pantalla Perfil. NOW no ofrece actualmente un control único para borrar todos los datos locales, una función para eliminar cuentas ni una opción para borrar los planes de nutrición guardados. Los registros de límites de uso siguen el proceso de limpieza descrito arriba. No se verificó la conservación de datos por proveedores ni por copias de seguridad del dispositivo, así que este borrador no ofrece garantías al respecto.
